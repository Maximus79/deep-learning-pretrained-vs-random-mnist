# Deep Learning Project — Pretrained vs. Randomly-Initialized Networks

A deep learning project (Projet Deep Learning II) designing a DNN for handwritten digit classification, comparing a pretrained network against one trained from random initialization. Studies the impact of training set size, network depth, and initialization strategy on performance, using the Binary AlphaDigits dataset for unsupervised pretraining experiments and MNIST for final evaluation.

**Author(s):** Maxime Appert

**Stack:** Python, PyTorch
